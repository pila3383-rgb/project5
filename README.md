# 🛡️ GhostTrace (v0.1-Demo)

**Автономный санитайзер документов и детектор цифровых следов с графическим интерфейсом.**

GhostTrace защищает корпоративную и личную приватность перед отправкой файлов контрагентам или публикацией в сети. Утилита работает **100% офлайн**, оснащена удобным тёмным GUI на базе `tkinter` и решает задачи базового форензик-аудита PDF.

📺 **[Смотреть видеодемонстрацию работы (YouTube)](https://youtu.be/AwvID5GSgBc?si=fxYYntZKdzRRQWuZ)**

---

## 🚀 Ключевые возможности

1. **Глубокая очистка контейнера (Binary Sanitizer):** Пересборка структуры документа PDF с полным удалением словаря метаданных, имён авторов, путей локальных серверов и ПО.
2. **Детектор стеганографии (Shannon Entropy):** Расчёт энтропии Шеннона по сырым байтам файла для выявления зашифрованных закладок и скрытых вставок.
3. **Стилометрический аудит (Anti-Stylometry):** Локальный анализ текста (средняя длина предложений, индекс лексического разнообразия TTR) для оценки риска деанонимизации автора.
4. **Асинхронный интерфейс (GUI):** Многопоточная обработка файлов без зависания окна с подробным цветовым логированием этапов сканирования.

## 📦 Установка и запуск

### Вариант 1: Готовый исполняемый файл (Windows)
1. Скачайте `GhostTrace_v0.1.exe` из раздела [Releases](../../releases).
2. Запустите приложение, нажмите **«Обзор...»** и выберите нужный `.pdf` документ.
3. Нажмите **«ЗАПУСТИТЬ АНАЛИЗ И ОЧИСТКУ»**. Очищенный файл сохранится рядом с суффиксом `_clean.pdf`.

### Вариант 2: Запуск из исходного кода
Требуется **Python 3.8+** (со стандартным модулем `tkinter`).

```bash
# Клонирование репозитория
git clone https://github.com/your-username/GhostTrace.git
cd GhostTrace

# Установка зависимостей
pip install pypdf

# Запуск GUI-приложения
python main.py
```

## 🛠 Технологический стек

* **Язык:** Python 3.8+
* **Графический интерфейс:** `tkinter` (кастомная тёмная тема, многопоточность через `threading`)
* **Парсинг и пересборка PDF:** `pypdf`
* **Сборка:** PyInstaller (`pyinstaller --onefile --windowed main.py`)

## ⚠️ Дисклеймер и безопасность

* Программа работает полностью локально — ваши документы никуда не отправляются.
